# Learning English Zone

App web para estudiar inglés a diario con métodos respaldados por evidencia: repaso espaciado, input comprensible, shadowing y corrección de los errores típicos de hispanohablantes. Corre en tu PC con modelos de IA locales.

> En construcción. El README completo llega con el issue #7.

## Estructura

```
backend/   API en FastAPI (Python)
frontend/  Interfaz en React + TypeScript
docs/      Plan, arquitectura y base metodológica
data/      Datos semilla (catálogo de errores, mazos)
scripts/   Utilidades del repo
```
